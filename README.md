# 🧮 Simple Calculator App

A beginner-friendly calculator built with **Python** and **Streamlit**.  
This app allows users to perform basic arithmetic operations (+, −, ×, ÷) through an interactive web interface.  

---

## 🚀 Features
- 🔢 **Input two numbers**  
- ➕➖✖️➗ **Perform addition, subtraction, multiplication, and division**  
- ✅ **Instant results with a single click**  
- ⚠️ **Error handling for division by zero**  
- 🌐 **Simple and modern web-based UI**
